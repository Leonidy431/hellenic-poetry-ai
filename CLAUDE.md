## 🧠 СИСТЕМА ПРИНЯТИЯ РЕШЕНИЙ: "ЛУЧШЕЕ ИЗ 299"

### Алгоритм выбора при неопределённости

```python
def select_best_algorithm(candidates: List[Algorithm], 
                         parameters: 48,
                         experts: 32) -> Algorithm:
    """
    Правило: "Где не понимаешь - выбирай лучшее по 48 параметрам"
    """
    
    # 1. Score all candidates on 48 parameters
    scores = {}
    for algo in candidates:
        scores[algo.id] = eval_48_parameters(algo)
    
    # 2. Weight by expert opinions
    expert_weights = get_expert_weights()  # 32 experts
    weighted_scores = apply_expert_weights(scores, expert_weights)
    
    # 3. Calculate consensus
    consensus = calculate_consensus(weighted_scores)
    
    # 4. If consensus > 0.8: return consensus winner
    if consensus.confidence > 0.8:
        return consensus.algorithm
    
    # 5. If ambiguity (0.5-0.8): ask highest-weight experts
    if 0.5 < consensus.confidence <= 0.8:
        specialist_opinions = query_top_experts(5)
        return resolve_with_experts(specialist_opinions)
    
    # 6. If unclear (< 0.5): choose most cited/reproducible
    if consensus.confidence < 0.5:
        return select_by_citation_index(candidates)
```

## 📖 ОСНОВНЫЕ ПРАВИЛА ПРОЕКТА

### ✅ ПРАВИЛО 1: Научная обоснованность

Любой выбор алгоритма должен быть подкреплён научными статьями из:
- PubMed (pubmed.ncbi.nlm.nih.gov)
- Google Scholar (scholar.google.com)
- arXiv (arxiv.org) для новейших исследований

### ✅ ПРАВИЛО 2: Консенсус специалистов

При выборе между несколькими подходами:
1. Получить оценку от 32 профильных специалистов
2. Взвесить по компетенции (32 веса)
3. Выбрать вариант с наивысшим консенсусом

### ✅ ПРАВИЛО 3: "Лучшее из 299"

Когда выбор неясен:
```
Сбор кандидатов → Оценка 48 параметров → 
Экспертный консенсус → Выбор победителя
```

### ✅ ПРАВИЛО 4: Документированный процесс

Каждое техническое решение должно содержать:
- Ссылку на научную статью
- Оценки по 48 параметрам
- Комментарии экспертов
- Обоснование выбора
