# 🎭 Техническое задание: Academia Lux - Hellenic Poetry AI Platform

## 📋 Описание проекта

**Academia Lux** - комплексная AI-платформа для:
- Создания стихов и песен (интеграция с Suno App)
- Обучения греческому, русскому и болгарскому языкам через погружение
- Интерактивных театральных постановок с изменяющимся сюжетом
- Православного образования и духовного развития
- Работы с текстами Библии и святоотеческой литературы

## 🏗️ Архитектура системы

### Технологический стек

**Backend:**
- Rust (производительность, безопасность)
- Tokio (async runtime)
- Axum (web framework)
- SQLite/PostgreSQL (database)

**AI Integration:**
- OpenAI GPT-4 / Claude (текстовая генерация)
- Suno API (музыкальная генерация)
- DALL-E / Midjourney (визуализация)
- DeepL Pro (переводы)
- Whisper (распознавание речи)

**Frontend:**
- Telegram Bot API
- Yandex Alice API
- Web интерфейс (React/Vue)
- Mobile app (Flutter)

## 📊 MVP (Минимально жизнеспособный продукт)

### Этап 1: Базовый функционал (2-4 недели)

1. **Telegram бот** с базовыми командами:
   - `/explain <слово>` - объяснение церковных терминов
   - `/translate <фраза>` - перевод богослужения
   - `/quote` - цитата дня из святых отцов
   - `/poem <тема>` - генерация стихотворения
   - `/lesson` - урок греческого языка

2. **AI интеграция:**
   - OpenAI GPT-4 для генерации текстов
   - DeepL для переводов
   - Базовая база данных (Google Sheets)

3. **Хранение данных:**
   - SQLite для локального хранения
   - Google Sheets для справочных данных

### Этап 2: Расширенный функционал (1-2 месяца)

4. **Генерация стихов и песен:**
   - Интеграция с Suno API
   - Генерация промптов для музыки
   - Экспорт в аудио форматы

5. **Обучение языкам:**
   - Интерактивные упражнения
   - Отслеживание прогресса
   - Система уровней (A1-C2)

6. **Интерактивный театр:**
   - Базовые сюжеты
   - Голосование зрителей
   - Генерация диалогов

### Этап 3: Полный функционал (3-6 месяцев)

7. **Православный ассистент:**
   - Работа с текстами Библии
   - Святоотеческая литература
   - Церковный календарь

8. **Игровая механика:**
   - Достижения и уровни
   - Рейтинг пользователей
   - Социальные функции

9. **Web и Mobile приложения:**
   - Web интерфейс
   - iOS/Android приложения
   - Синхронизация данных
